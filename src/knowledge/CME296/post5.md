# 第五讲

上一讲解决了两个问题：**图片可以在潜空间里生成，生成过程还可以受到条件引导**。于是，本讲我们要设计的网络，可以先统一写成：

::: center

$u_\theta(z_t,t,c)$

:::

其中 $z_t$ 是当前的带噪潜变量，$t$ 是时间，$c$ 是生成条件，然后进入模型后，输出的是 $u_\theta$ 速度

![模型输入与输出](/assets/images/CME296/post5/img1.png)

::: tip 生成范式和具体网络架构是两回事

Diffusion、Score Matching、Flow Matching 讨论的是生成过程和学习目标；U-Net、Transformer 讨论的是实现预测的网络结构。不是换成 Transformer，就不能预测噪声了；也不是预测速度，就必须用 Transformer。

:::

## 我们需要一个什么样的网络？

给图片加噪声不难，毕竟第一讲就讲了。然而要从噪声里找回一张合理的图片，对网络还是有点要求的：

- **全局理解**：熊的头应该连在身体上，不能跑到书里面
- **局部细节保持**：毛发、边缘、纹理也得像样，不能只有一个模糊轮廓
- **听条件的话**：同一份输入，时间不同、提示词不同，应该给出不同的预测
- **可接受的计算成本**：图片变大、模型变大以后，计算成本不能雷霆变大

前两个要求就有点拉扯：只看局部，容易顾不上全局；把东西压得太小，又容易丢掉局部细节。我们先看看卷积这边怎么处理。

## U-Net

### 为什么是卷积？

卷积的具体计算，可以回顾[之前的博客](https://gstech.fun/knowledge/AI/post2.html)

有的卷积核擅长找边缘，有的找角点，后面的层再把这些特征组合起来。它不需要对图像每个位置单独学一套参数，同一种纹理换了位置，也能用同样的规则处理

这就叫给模型加入了**归纳偏置（inductive bias）**：我们事先告诉模型，图像里的局部关系很重要（毕竟人眼其实也是通过扫描局部来看图的），而且很多局部规律可以在不同位置复用

不过，一层小卷积只能看到一小块区域，也就是它的**感受野**比较小。多叠几层，或者先把特征图下采样，同一个特征位置就可以逐渐汇集更大范围的信息

### 缩小再放大

既然缩小以后更容易看到全局，那就先缩小；但最后还要输出和当前输入对应的结果，那就再放大回来。这个思路形成了一个很直观的 U 形结构，也就是 **U-Net**

![U-Net 的下采样路径、上采样路径与横向跳跃连接](/assets/images/CME296/post5/img2.png)

左边是下采样路径：一边卷积提取特征，一边降低空间分辨率。越往下走，单个位置汇集的信息范围越大。常见设计还会增加通道数，让更小的特征图容纳更丰富的特征

右边是上采样路径：逐渐增加空间分辨率，再用卷积整理特征。上采样可以用转置卷积，也可以先插值再卷积

最后，通过输出层把通道数调整到任务需要的数量。对速度预测而言，输出应该和 $z_t$ 有相同的形状，这样才能逐元素更新潜变量。

### 跳跃连接

问题来了：既然下采样会损失信息，那右边放大的时候，图片细节怎么办？纯猜吗？

U-Net 的办法是，**让左边相应分辨率的特征，走一条近路，直接送到右边。** 图中横着跨过去的箭头，就是跳跃连接（skip connection）

深层路径提供大范围的结构信息，浅层传来的特征则保留更多空间细节。上采样时把两者结合，既知道整体应该是什么，也有机会找回这里的边缘在哪里

原始 U-Net 的这些连接主要是把特征沿通道维**拼接**起来；普通残差块则常把输入和分支输出**相加**。都是让信息走近路，但具体操作不一样。

### 时间 $t$ 和条件 $c$ 怎么办

到这里，我们还只处理了 $z_t$。时间 $t$ 和条件 $c$ 总不能在旁边站着看，它们也得参与计算。

课程概括了三种方式：

1. **直接加进去**：把时间或条件映射成向量，调整到对应通道数，再广播到特征图各个位置并相加。
2. **缩放、平移**：由时间和条件生成一组参数，控制特征的强弱和偏移。
3. **Cross-Attention**：让图像特征主动读取条件中的信息。

先记住它们，后面看 DiT 的时候，还会遇到这些思路。

所以，U-Net 并不是只能处理像素。DDPM 可以在像素空间里用它，潜空间扩散也可以在 VAE 的潜变量上用它。**换了生成空间，预测网络的基本思路仍然可以沿用。**

### 训练完以后，怎么拿来生图？

到这里还有个问题：U-Net 我们会搭了，可训练完以后，把什么塞进去，才能真正得到图片？是不是还得接上上一讲的 VAE？

先记住：**U-Net 通常不是一次调用就直接画完，而是负责预测当前这一步需要的量。采样器再根据预测更新状态，反复调用同一个 U-Net，直到生成结束。** 推理时参数固定，不再计算训练损失或更新权重。

至于需不需要 VAE，要看这个 U-Net 当初是在哪个空间里训练的，不能在推理时随便换。

#### 如果在像素空间训练

如果训练时，U-Net 看到的就是带噪的像素图，比如原始 DDPM，那么推理时就抽一张同样尺寸的高斯噪声图 $x_T$，然后逐步去噪：

::: center

$x_T\sim\mathcal N(0,I)\quad\longrightarrow\quad x_{T-1}\quad\longrightarrow\quad\cdots\quad\longrightarrow\quad x_0$

:::

每一步，把当前 $x_t$、时间 $t$，以及模型需要的条件送入 U-Net。假如它学的是噪声预测，就输出 $\varepsilon_\theta(x_t,t,c)$；采样器按照相应的反向更新公式，算出下一步的 $x_{t-1}$。具体采样公式可以回顾第一讲。

所以不是简单地“每次减掉 U-Net 输出的噪声”就行，还要使用训练设定对应的系数；像 DDPM 这样的随机采样过程，部分步骤还会加入随机噪声。最后得到的 $x_0$ 已经在像素空间里，**不需要再经过 VAE Decoder**。

#### 如果在潜空间训练

如果用的是第四讲的潜空间扩散，训练流程通常分成两部分：先准备好 VAE，再用它的 Encoder 把训练图片编码成潜变量；对潜变量加噪，让 U-Net 学习对应的预测任务。此时通常固定 VAE 的参数，训练 U-Net。

到了从零生图的时候，已经没有一张原图等着压缩了，因此**直接在模型使用的潜变量坐标中采样高斯噪声，不用先让噪声经过 VAE Encoder**。为便于和上面的 DDPM 对照，这里继续使用从 $T$ 到 $0$ 的去噪记法：

::: center

$z_T\sim\mathcal N(0,I)\quad\longrightarrow\quad z_{T-1}\quad\longrightarrow\quad\cdots\quad\longrightarrow\quad z_0\quad\longrightarrow\quad\hat x=D_\psi(z_0)$

:::

前面一长串，由 **U-Net 加采样器**完成：U-Net 预测，采样器更新，重复多次。最后得到干净的潜变量，再交给 **VAE Decoder**，一次解码成图片。实际模型可能还会对潜变量做缩放、偏移，解码前要按该模型的约定还原。

如果是文字生成图片，还要先用**文本编码器**把提示词变成条件表示 $c$，供每一步预测使用。上一讲提到的 CLIP 文本编码器就是一种选择，也有模型采用其他文本编码器。

::: tip 概念区分

- **VAE Encoder**：把已有图片编码成潜变量，训练时会用到；图生图时通常也需要它编码输入图片
- **VAE Decoder**：把生成完成的潜变量解码成像素图片，潜空间生图的最后要用到
- **文本编码器**：把提示词变成条件表示，负责告诉生成网络要画什么
- **U-Net 的下采样路径**：虽然也经常被叫作 Encoder，但它是 U-Net 内部的特征处理部分，和 VAE Encoder 不一样

:::

## DiT

### 为什么还需要 Attention？

U-Net 已经能兼顾局部和全局了，那为什么还要换？

想象一块带有重复花纹的布，它在图像左边露出一角，又在右边露出一角。两边距离很远，但纹理最好一致。卷积不是处理不了这种关系，而是需要经过多层计算，把信息逐步传过去。

Attention 则提供了更直接的办法：**让相距很远的两个位置，也能直接交换信息。** 它不强制每次只和附近的小窗口交流，而是根据当前内容决定该看谁。

Self-Attention 的具体计算可以回顾[Transformer 笔记](https://gstech.fun/knowledge/AI/post6.html)。放在这里，我们关心的是：既然图片已经能切成 token，那就可以让这些 token 通过 Attention 交流，再用 Transformer 完成预测。

这就是 **DiT（Diffusion Transformer）** 的基本思路。

![原始 DiT 的总体结构与内部 Transformer Block](/assets/images/CME296/post5/img3.png)

### 这次切的是潜变量

上一讲讲 ViT 时，我们把图片切成 patch。现在做的事情类似，只不过通常切的是**带噪潜变量**。

设潜变量的形状为 $H_z\times W_z\times C$，把它切成边长为 $p$ 的小块，假设长宽都能整除 $p$，那么 token 数量就是：

::: center

$T=\frac{H_zW_z}{p^2}$

:::

每个 patch 原本有 $p^2C$ 个数，把它摊平，再通过线性投影，变成 $d$ 维向量。于是整个输入从一个空间张量，变成一个 token 矩阵：

::: center

$z_t\in\mathbb R^{H_z\times W_z\times C}\quad\longrightarrow\quad X\in\mathbb R^{T\times d}$

:::

例如 $32\times32\times4$ 的潜变量，采用 $p=2$ 的 patch，就会得到 $16\times16=256$ 个 token；每个 patch 摊平后有 $2\times2\times4=16$ 个数，再投影到模型使用的维度。

这里的 patch 投影不是又训练了一个 VAE。VAE 已经完成了图像压缩，这一步只是**把潜变量整理成 Transformer 好处理的输入形式**。

再给 token 加上位置信息，就可以送入多个 DiT Block 了。为什么需要位置编码，我们在文章最后单独说。

## 核心：让模型听懂时间和条件

如果只让图像 token 互相交流，那模型仍然不知道我们要画什么，也不知道现在还有多少噪声。所以，DiT 的关键不只是“换成 Transformer”，还有**条件到底怎么影响每一层的计算**。

### 三种条件注入

原始 DiT 比较了几种条件注入方式，其中三类比较好理解：

| 方式 | 怎么理解 |
| --- | --- |
| In-context conditioning | 把条件也变成 token，放进序列，一起做 Self-Attention |
| Cross-Attention | 图像 token 提供 Query，条件 token 提供 Key 和 Value，让图像读取条件 |
| Adaptive Layer Norm | 不把条件塞进序列，而是用条件控制特征的缩放、平移 |

下面三张图，分别对应自适应归一化、交叉注意力和序列内条件注入：

![原始 DiT 对不同条件注入方式的实验比较，FID 越低越好](/assets/images/CME296/post5/img7.png)

在图中这组实验里，**adaLN-Zero** 的结果最好。这里的指标 FID，简单理解就是比较生成图像与真实图像的特征分布，通常越低越好；它不是“每张图打多少分”，也不能单独代表提示词遵循程度。

这个结论有实验范围，不能直接推成“所有文生图模型都应该只用 adaLN”。先看看它为什么有效。

### adaLN

假设提示词是一只“棕色、毛茸茸的泰迪熊”。在生成刚开始、噪声还很多的时候，我们更需要先确定熊的大体形状和布局；快生成完的时候，才有条件处理毛发等局部细节。

因此，条件的作用不应该始终一模一样。我们希望模型根据时间和内容，动态调节特征。

**adaLN（Adaptive Layer Normalization，自适应层归一化）** 就是在 Layer Norm 的基础上，让条件来决定后面的缩放、平移：

::: center

$\operatorname{adaLN}(X;t,c)=(1+\gamma(t,c))\odot\operatorname{LN}(X)+\beta(t,c)$

:::

别被名字吓到，拆开就三步：

1. 对每个 token 的特征做 Layer Norm；
2. 乘上由条件决定的缩放量 $1+\gamma$；
3. 加上由条件决定的平移量 $\beta$。

其中 $\gamma$、$\beta$ 是向量，不是一个统一的数字。它们由条件网络产生，可以对不同特征通道施加不同影响，再沿 token 维广播。$\odot$ 表示逐元素相乘。

可以把它理解成一排旋钮：现在是强噪声阶段，就把某些特征调强一点；到了后期，又换一套调法。至于每个通道具体负责什么，是模型学出来的，不是我们事先规定“第十个通道必须识别棕色”。

### adaLN-Zero

缩放、平移之外，再加一个门控量 $\alpha$，控制这一条计算分支对原输入贡献多少。一个简化的残差子层可以写成：

::: center

$X'=X+\alpha\odot F\!\left((1+\gamma)\odot\operatorname{LN}(X)+\beta\right)$

:::

这里 $F$ 可以是 Attention，也可以是前馈网络。$\gamma$、$\beta$ 调节送进分支的特征，$\alpha$ 则控制分支结果加回来多少。

**Zero** 的关键在初始化：让生成这些调制参数的最后一层从零开始，尤其让门控 $\alpha$ 初始为零。这样一开始残差分支的贡献为零，整个 Block 接近恒等映射，之后再逐渐学会怎样修改输入。

![DiT Block 中的 adaLN-Zero：Attention 和前馈分支分别接受条件调制及门控](/assets/images/CME296/post5/img8.png)

一个 DiT Block 里有两条主要分支：Self-Attention 和逐 token 的前馈网络。每条分支各需要一套门控、缩放、平移，所以条件 MLP 总共要生成六组向量：

::: center

$\alpha_1,\gamma_1,\beta_1,\qquad\alpha_2,\gamma_2,\beta_2$

:::

图看着复杂，其实就是“归一化、调制、计算、门控、残差相加”做两次。第一遍让 token 之间交换信息，第二遍进一步加工每个 token 的特征。

::: tip 条件注入和 CFG 是两件事

条件注入解决的是：**给定条件，网络内部怎么使用它？**

上一讲的 CFG 解决的是：**推理时，怎么组合条件预测和无条件预测，增强引导？**

两者可以同时使用。不是加了 adaLN，CFG 就自动消失了。

:::

## 完整过程

模块看完，我们把它们装起来。这次使用第三讲的 Flow Matching 视角，约定 **$t=0$ 是噪声端，$t=1$ 是数据端**。

### 一次网络预测

先在潜变量空间里抽一份高斯噪声 $z_0$。给定当前状态 $z_t$，一次预测的流程是：

1. 把 $z_t$ 切成 patch，线性投影成 token，并加入位置信息；
2. 把时间 $t$ 编码成向量，把条件 $c$ 编码成对应表示，再组合成条件嵌入；
3. 条件嵌入经 MLP 生成各层需要的调制参数；
4. 图像 token 经过多个 DiT Block，不断交换和加工信息；
5. 最后归一化、线性投影，将每个 token 转回 patch 对应的数值；
6. 把 patch 按原来的空间位置拼回去，也就是 **unpatchify**。

![带条件调制的 DiT 计算流程：从 patch token 到速度预测](/assets/images/CME296/post5/img9.png)

输出就是 $u_\theta(z_t,t,c)$。它的形状与 $z_t$ 一致，但它表示的是**速度场在当前位置的预测值**，不是已经生成完的图片。

原始 DiT 的图还画了噪声和对角协方差输出，那是原始扩散设定中的输出头。换成这里的速度预测任务时，要使用与相应训练目标匹配的输出头和损失，不能只把图里的 Noise 改个名字，就当模型已经会预测速度了。

### 走一步做一步

知道速度以后，用之前学过的欧拉法走一小步：

::: center

$z_{t_{i+1}}=z_{t_i}+(t_{i+1}-t_i)\,u_\theta(z_{t_i},t_i,c)$

:::

然后把更新后的潜变量、下一个时间，以及相同的条件，再送进网络。**同一个网络反复调用，输入的状态和时间不断变化。** 不是每走一步就换一个模型，也不是每一步都要重新训练。

一直走到 $t=1$，得到最终潜变量 $z_1$，再送进第四讲的 VAE Decoder，才得到像素空间里的图片：

::: center

$z_0\sim\mathcal N(0,I)\quad\longrightarrow\quad z_1\quad\longrightarrow\quad\hat x=D_\psi(z_1)$

:::

到这里，前三讲的“怎么走”、第四讲的“在哪走”，和这一讲的“谁来预测方向”，终于接起来了。

## 扩大 DiT，不只是增加参数

既然 Transformer 用起来很方便，那我们能不能继续加大？可以，而且原始 DiT 实验发现，在其测试范围内，增加模型计算量与更好的生成结果有关。

![DiT 的模型规模配置及生成结果变化](/assets/images/CME296/post5/img10.png)

扩大规模有两类直接办法：

- **增加网络规模**：增加层数、隐藏维度等；
- **减小 patch**：同一份潜变量切成更多 token，让网络在更细的空间粒度上处理信息。

第二点特别容易被忽略。假如 patch 边长减半，token 数就会变成原来的四倍；标准全局 Self-Attention 中，注意力矩阵的元素数量随 $T^2$ 增长，这部分就可能变成十六倍。

但整个网络还有投影、前馈等计算，所以不能直接说“总计算量一定变成十六倍”。我们只需要记住：**模型参数量差不多，实际计算成本也可能差很多。**

因此，比较模型时除了看参数，还要看 token 数量、分辨率和 FLOPs。图中给出的规模趋势也是实验结果，不代表把模型无限加大，就一定能无条件地变好。

## 多模态 DiT

### 统一调制还不够细

前面讲 adaLN 时，同一组 $\gamma$、$\beta$ 会广播到所有图像 token。这很适合给整个图像提供一个全局控制信号，但复杂提示词往往更具体：

> 一只棕色泰迪熊，抱着一本白色封面的书，坐在红色椅子上。

这里不只是“整体画一只熊”，还有不同对象、颜色和关系。我们希望画熊的位置多关注“棕色泰迪熊”，画书的位置多关注“白色封面”，而不是把所有细节先挤进同一个全局向量里，再统一调制。

::: tip 统一调制，不等于所有 patch 输出一样

每个 patch 原本的内容、位置信息，以及 Attention 读到的信息都不同，因此即使用相同的调制参数，输出也可以不同。

这里讨论的是条件交互的粒度：能否让不同位置，更直接地读取不同的文本内容。

:::

这就又轮到 Attention 出场了。

### Cross-Attention 和 Joint Attention

**Cross-Attention** 可以理解成图像去查文字：图像 token 产生 Query，文本 token 产生 Key 和 Value，每个图像位置自己决定重点读取哪些文字。

**Joint Attention** 则进一步让不同模态的 token 共同参与注意力计算。在常见实现里，会把两边的 Key、Value 等沿序列维合起来，使图像和文字能在同一轮计算中交互。

这里不要求所有投影层、前馈层都共享参数。不同模态可以先用各自的参数处理，再进入共同的 Attention。

### 双流、单流、混合

课件接下来把这些设计分成三类：

| 路线 | 主要特点 | 例子 |
| --- | --- | --- |
| 双流 | 图像、文本保留各自的处理分支，在注意力中交互 | SD3、Qwen-Image |
| 单流 | 将多模态 token 放入统一的主干序列处理 | Z-Image |
| 混合 | 同时使用双流与融合后的单流模块 | FLUX.1 Kontext |

![双流多模态 DiT Block](/assets/images/CME296/post5/img11.png)

上图来自课件展示的 Qwen-Image 结构。两边各有归一化、调制和前馈等模块，中间则有共同的注意力计算。**双流不是两边各算各的、最后才碰头**，而是保留各自处理方式，同时不断交换信息。

单流也不意味着输入的每一步都共用同一个编码器。文字仍然需要文本编码器，图像仍然可以经过 VAE；这里主要讨论的是后面的生成主干怎样处理这些表示。

![FLUX.1 Kontext](/assets/images/CME296/post5/img12.png)

混合设计则把两种方式接起来：先保留模态分支，再融合成统一序列。图中的 FLUX.1 Kontext 还把参考图片编码后作为输入，因此不仅能根据文字生成，也能利用已有图片进行编辑。

这一段先掌握结构上的区别就够了。它们是在回答同一个问题：**图像和文字，应该在哪里分开加工，在哪里交流？**

## 别忘了：模型怎么知道位置？

前面把潜变量切成 token 时，我们顺手加了位置编码。现在补上原因。

Self-Attention 根据 token 内容计算关联，但不会凭空知道“这是左上角，那是右下角”。如果只把一堆 patch 向量交给它，却没有位置信息，空间关系就缺了一块。

文字的词序也一样。“熊在读书”和“书在读熊”，词差不多，意思可差远了。

### 正弦、余弦位置编码

经典方案是，用一组不同频率的正弦、余弦，给每个位置生成一个向量。设位置为 $m$，向量维度为偶数 $d$，则：

::: center

$\operatorname{PE}(m,2i)=\sin\!\left(\frac{m}{10000^{2i/d}}\right)$

$\operatorname{PE}(m,2i+1)=\cos\!\left(\frac{m}{10000^{2i/d}}\right)$

:::

其中 $i=0,1,\ldots,d/2-1$。每对维度使用同一频率的 sin 和 cos，不同维度对的频率不同。最后，把位置向量加到对应的 token 表示上。

![正弦位置编码的数值分布](/assets/images/CME296/post5/img13.png)

直观理解就是：有的维度随位置变化得快，有的变化得慢。把这些信号组合起来，模型就有了一套区分位置、利用位置关系的线索。

而且，sin 和 cos 的和差公式，使同频率位置编码之间的关系可以用位置差表达，这也是它适合提供相对位置线索的原因。不过，实际 Attention 还包含内容表示和可学习投影，不能理解成“注意力分数只取决于距离”。

对于图片，我们还需要表达行、列两个方向的位置，可以分别编码后组合。课件前面的现代模型图里还出现了 RoPE 等设计，但这批截图最后只展开到了正弦位置编码，这里先把这个基础版本讲清楚。

## 小结

这一讲其实就是把前面那个神秘的 $u_\theta$ 拆开了。

U-Net 通过下采样整合大范围信息，通过上采样恢复空间分辨率，再用跳跃连接保住细节；DiT 则把当前状态切成 token，用 Attention 交换信息，通过条件注入让时间和提示参与计算。adaLN-Zero 提供了一种从近似恒等映射开始学习的条件调制方式，更复杂的文字交互则引出了多模态 Attention 和单流、双流、混合结构。

最后别忘了，**网络一次只给出当前这一步需要的预测**。真正把噪声变成图片，还得靠前面学过的迭代更新，再由 VAE Decoder 把最终潜变量变回像素。
